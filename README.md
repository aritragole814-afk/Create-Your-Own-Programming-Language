# NovaLang: Custom Programming Language Implementation

A full-featured, lightweight educational programming language and tree-walk interpreter built in Python from first principles for Compiler Design Project-Based Learning (PBL).

NovaLang implements a full compiler front-end pipeline:
1. **Lexical Analysis (Scanner / Tokenizer)**: Generates typed tokens with line and column metadata.
2. **Syntax Analysis (Recursive Descent Parser)**: Constructs an Abstract Syntax Tree (AST) while enforcing operator precedence.
3. **Semantic Checking & Scoped Environments**: Manages symbol tables, block scoping, and runtime validation.
4. **Interpreter / Evaluator**: Direct AST tree-walk evaluation without host-language `eval()` or `exec()`.

---

## Language Highlights & Features

- **Variables & Declarations**: Declare variables with `let <name> = <expr>;` and reassign values with `<name> = <expr>;`.
- **Data Types**: Integers (`42`), Floats (`3.14`), Strings (`"hello"`), and Booleans (`true`, `false`).
- **Operators & Precedence**:
  - Arithmetic: `+`, `-`, `*`, `/`, `%` (modulo), unary negation `-`.
  - Comparison: `==`, `!=`, `<`, `<=`, `>`, `>=`.
  - Logical: `and` (`&&`), `or` (`||`), `not` (`!`) with short-circuit evaluation.
  - String concatenation via `+`.
- **Control Flow**:
  - Conditional branching: `if (<cond>) { ... } else if (<cond>) { ... } else { ... }`.
  - Loops: `while (<cond>) { ... }`.
- **I/O**: Formatted `print(...)` statement supporting multiple arguments.
- **Comments**: Single-line (`// ...`) and multi-line (`/* ... */`).
- **Developer Tools**:
  - `--tokens`: Inspect raw token stream from the Lexer.
  - `--ast`: Inspect hierarchical syntax trees from the Parser.
  - Interactive REPL with multiline block auto-detection.

## Quick Start & Usage

### Prerequisites
- Python 3.10+ (Standard library only; zero external dependencies required)

### 1. Run Example Programs

```bash
# Run Hello World
python -m src.main examples/hello.nova

# Run Fibonacci sequence generator
python -m src.main examples/fibonacci.nova

# Run FizzBuzz algorithm
python -m src.main examples/fizzbuzz.nova
```

### 2. Inspect Compiler Phases

To demonstrate the inner workings during presentations or vivas:

```bash
# View tokens generated by the Lexer
python -m src.main --tokens examples/factorial.nova

# View the Abstract Syntax Tree generated by the Parser
python -m src.main --ast examples/factorial.nova
```

### 3. Launch the Interactive REPL

```bash
python -m src.main
```

Type statements ending with `;` or blocks inside `{ ... }`. Enter `:quit` to exit.

### 4. Run Test Suite

```bash
python -m unittest discover -s tests -v
```

All 22 unit tests validate lexical analysis, syntax rules, precedence, runtime scoping, arithmetic, loops, and error reporting.
